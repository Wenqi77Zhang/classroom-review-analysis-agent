## 自动化优先级

- P0：核心流程或安全边界，失败时不得合并。
- P1：主要状态和错误恢复，Day 1–2 必须覆盖。
- P2：体验与可访问性增强，在 M1 核心链路稳定后补充。

## 首页与课堂创建

| 优先级 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| P0 | 首页表达产品边界 | 打开首页 | 显示目标用户、单节课堂复盘价值和“系统不自动给教师打分”的边界 |
| P0 | 创建课程与课堂 | 填写合法名称并提交 | 只提交一次；成功后获得课堂标识并进入复盘任务入口 |
| P1 | 必填项缺失 | 空提交或只输入空白字符 | 页面就地提示，不发送请求，不清空用户已填写内容 |
| P1 | 后端不可用 | 创建请求返回失败 | 显示可理解原因和重试入口，不暴露堆栈或内部地址 |
| P2 | 键盘操作 | 只使用键盘完成表单 | 焦点顺序正确，标签与错误提示可被辅助技术识别 |

## 对话追问与分析契约

| 优先级 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| P0 | 目标信息不足 | 提交模糊复盘目标 | Agent 进入追问状态，不直接开始分析 |
| P0 | 修改分析契约 | 修改范围、关注维度或证据条件 | 契约摘要同步更新，状态回到待确认 |
| P0 | 确认契约 | 点击确认按钮两次 | 只创建一个处理任务，按钮在请求期间禁用 |
| P0 | 无证据条件 | 尝试允许无来源判断进入报告 | 页面保持“无证据不得进入报告”的强制边界 |
| P1 | Agent 回复失败 | 请求超时或服务失败 | 保留教师原输入，提示重试，不生成伪造回答 |

## 上传入口与处理状态

| 优先级 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| P0 | 合法视频上传 | 选择支持的视频文件 | 获取预签名信息并显示真实上传进度；前端不接触长期存储密钥 |
| P0 | 上传完成后登记 | 对象上传成功 | 调用后端确认接口后才创建文件记录和处理任务 |
| P0 | 更换输入 | 上传第二段不同视频 | 创建新的资源和任务，不复用旧分析结果 |
| P1 | 非法类型或超限 | 选择不支持或过大文件 | 上传前阻止并说明限制 |
| P1 | 上传中断 | 模拟网络中断 | 显示失败环节和重试入口，不显示虚假 100% |
| P1 | 后台处理阶段 | 上传完成后轮询任务 | 区分上传、音频抽取、分段、识别、翻译、证据索引和分析 |

## 报告页面

| 优先级 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| P0 | 内容门禁 | 存在 pending、accepted、modified、rejected 结论 | 只组合 accepted 和带人工确认内容的 modified 结论 |
| P0 | 修改后预览 | 编辑已确认内容 | 预览与编辑内容一致，并保留来源引用 |
| P0 | 导出 | 点击导出 | 导出进行中不可重复提交；失败可重试且不丢编辑内容 |
| P1 | 尚未完成复核 | 仍有待复核结论时打开报告 | 明确提示未复核数量，不把待复核内容自动写入报告 |

## 不得通过的实现

- 固定计时器假装真实上传或处理进度。
- 在前端源码、日志、快照或测试数据中出现真实密钥、Token 或预签名 URL。
- 后端失败时回退到写死的成功数据，却不标注模拟状态。
- 使用旧视频的逐字稿或分析结果响应新输入。
- 将 pending、rejected 或缺少证据的结论导入报告。
