## 审查范围

本次按“复盘目标—Agent 追问—分析契约—资料选择—任务状态—证据复核—报告编辑/预览/导出”逐段检查，不把 Mock、浏览器会话状态或打印功能写成后端真实能力。

## 发现并修复的流程断点

| 断点 | 风险 | 修复 | 当前边界 |
|---|---|---|---|
| 首次输入后直接形成契约 | 没有体现 Agent 必要追问 | 增加范围、证据和双语要求追问，第二轮输入后才形成契约 | 追问仍是本地固定逻辑，未调用真实 Agent |
| 未选择视频也能切换任务状态 | 可绕过真实视频门禁 | 上传组件向上返回视频就绪状态；没有视频时任务预览按钮禁用 | 文件仍只在浏览器校验，未真实上传 |
| 失败状态缺少清晰重试路径 | 无法验证错误和重试交互 | 增加失败阶段、示例原因和安全重试预览 | 未调用后端重试 API |
| 复核结果无法进入报告 | 页面之间流程断裂 | 已接受/已修改的演示复核通过 `sessionStorage` 交接报告 | 只限当前浏览器会话，未写入数据库 |
| 修改结论未填写说明也能进入报告 | 违反教师确认门禁 | 修改状态必须填写说明才能进入报告 | 服务端仍需重复校验 |
| 报告页面只是 TODO | 无法审查编辑与导出流程 | 完成编辑、预览、复核过滤和浏览器打印/PDF | DOCX、服务器保存和真实数据等待报告 API |
