## 发现的问题

复盘任务页的核心对话区和分析契约区使用 `[data-reveal]` 进入动画。修改前，
CSS 默认将这些内容设为透明，必须等待客户端 JavaScript 的
`IntersectionObserver` 初始化后才显示。页面初始化较慢或脚本不可用时，用户
会先看到大块空白；这会让装饰性动画成为访问核心流程的前置条件。

## 修改

- 将核心内容改为默认可见。
- 仅在浏览器支持 `IntersectionObserver` 且用户未开启“减少动态效果”时启用
  显现动画。
- 组件卸载或路由切换时移除动画能力标记。
- 增加 UI 基线回归断言，防止再次把核心内容默认隐藏。

报告页面审查还发现：

- 打印样式引用不存在的 `.site-nav`，站点页眉、演示提示和会话交接提示可能
  混入 PDF。现已改为隐藏实际存在的站点壳层与非报告提示，只保留报告正文。
- 从编辑模式点击打印原本依赖零延迟定时器，不能严格保证预览已经渲染。现改为
  先切换预览，待 React 完成渲染后再调用浏览器打印。
- 成员 1 在 Codex 内置浏览器中确认按钮能够从编辑模式切换到预览模式，并通过
  `Ctrl+P` 打开系统打印预览。人工核对确认打印版只保留报告正文，不包含顶部
  导航、Mock 横幅、复核门禁提示或导出按钮。
- 页面保留 Chrome/Edge 与 `Ctrl+P` 兜底提示，以覆盖打印弹窗被嵌入环境拦截
  的情况；该提示不会进入打印版。
- 增加报告打印隔离与打印时序回归断言。
