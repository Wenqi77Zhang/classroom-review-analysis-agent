# 课堂复盘与教学分析 Agent：测试与验收记录

> 本文统一记录测试方法、样例许可、阶段验收、失败恢复、真实 E2E 和剩余门禁。  
> 产品范围与完成度见 [`../docs/product-and-technology-handbook.md`](../docs/product-and-technology-handbook.md)。

## 1. 验证口径

### 1.1 状态定义

| 状态 | 判定方式 |
|---|---|
| 自动化通过 | 指定命令在记录基线执行成功 |
| 技术链路通过 | 真实数据经过代码、数据库、模型或工具并得到可核查结果 |
| 人工通过 | 按步骤实际操作并保存现象、追踪号或输出摘要 |
| 局部通过 | 部分阶段真实通过，但仍有明确缺口 |
| 未完成 | 没有实现，或没有足够证据证明可用 |

Mock、静态页面、固定录像和 TODO 不能证明真实链路。条件跳过的测试必须说明缺少何种外部服务，
不能并入通过数量。开发者操作不等于非开发教师用户验收。

### 1.2 证据最小集

每次关键验收至少记录：

- 日期、分支或提交；
- 输入类型、来源/许可和脱敏状态；
- 执行命令或浏览器步骤；
- 结果、失败阶段和安全追踪号；
- 问题、修改和复测结论；
- 未覆盖范围。

不得记录视频内容、学生身份、Cookie、Authorization、服务令牌、数据库密码、对象存储密钥、
完整预签名 URL 或模型隐藏推理。

## 2. 自动化与发布命令

### 2.1 一键验证

Windows：

```powershell
.\verify.ps1
```

macOS/Linux：

```bash
./verify.sh
```

验证脚本应覆盖 Python 静态检查与测试、前端测试、TypeScript 类型检查、Next.js 生产构建、
Markdown/骨架约束和敏感文件扫描。任何一步失败都应返回非零退出码。

### 2.2 分模块命令

Python：

```powershell
.\.venv\Scripts\ruff.exe check .
.\.venv\Scripts\pytest.exe -q
```

前端：

```powershell
Set-Location .\frontend
npm test
npm run typecheck
npm run build
```

数据库集成测试需提供隔离的 PostgreSQL 测试库；真实 B2、Ollama、FFmpeg 和 Whisper 测试只在
明确配置的环境启用。测试不应读取开发者私人 `.env` 或将真实凭据输出到 CI。

## 3. 测试数据与隐私

### 3.1 数据分层

| 层级 | 用途 | 仓库策略 |
|---|---|---|
| 合成小样例 | 单元测试、边界与错误码 | 可提交，无真实身份信息 |
| 获授权公开课 | 本地/私有真实媒体链路 | 只记录来源、许可、哈希和脱敏摘要，不提交媒体 |
| 私密课堂 | 未来隐私场景 | 默认本地处理，须单独授权与影响评估 |

真实样例至少包含一门计算机或人工智能课和一门人文社科课；优先中英混合以展示双语能力，
但不要求必须有答疑环节。若只完成其中一个样例，不得声称覆盖两类课程。

### 3.2 输入身份

每个真实输入使用内部 `case_id`，记录来源 URL、许可、下载日期、文件哈希、时长、语言和是否
脱敏。公开仓库只保留这些元数据的安全摘要。第二输入必须与第一输入内容不同，不能只是重命名。

### 3.3 双语材料

教师补充译文只接受 UTF-8 SRT/VTT，并检查时间范围、顺序、重叠、空片段和中文覆盖。
补充译文用于对齐，不替代视频、FFmpeg 或 ASR 原文。纯中文课堂可以关闭双语契约；英文或中英
混合课堂若要求双语而译文不完整，系统必须失败关闭。

## 5. 真实单输入技术 E2E

### 5.1 前置条件

- 使用获授权真实视频，不提交到仓库；
- PostgreSQL、私有 B2、FastAPI、Worker、Ollama Agent 和前端均使用当前代码；
- Worker/Agent 服务令牌不同；
- 浏览器来源与 B2 CORS 精确匹配；
- 日志和截图已脱敏。

### 5.2 已验证链路

1. 浏览器建立 HttpOnly 演示会话并创建课程、课堂和分析契约。
2. 后端签发限时 PUT，浏览器上传到私有 B2。
3. 后端 HEAD 核对对象存在、大小和类型后确认资产并创建任务。
4. Worker 从受限下载 URL 获取对象，完成 FFmpeg、Whisper 和时间戳逐字稿写回。
5. Agent 读取分析契约与证据，调用 Ollama `qwen3.5:4b` 生成 3 条结构化结论。
6. 通过公开业务接口分别执行接受、修改确认和驳回，并核对复核历史。
7. 报告只纳入 accepted/modified，使用教师改写文本，排除 rejected 和原模型旧文本。
8. Markdown、HTML、PDF 三种导出对象实际生成并可下载。

### 5.3 结论边界

该验收证明一条真实数据技术链路，不证明第二输入、自动翻译、课件证据、正式部署或非开发教师
独立操作。只有这些剩余门禁也通过后，才能声明 M1 完成。

## 6. 失败与恢复

### 6.1 浏览器会话失效

**现象：** 深链接报告或任务返回 401，页面提示建立安全演示会话。  
**处理：** 通过服务端 `/api/session/demo` 设置短期 HttpOnly Cookie，再重试原请求。  
**边界：** 不把 JWT 写入 `localStorage`，不在错误信息中输出令牌。

### 6.2 B2 CORS 来源不一致

**现象：** 预签名成功，但浏览器 PUT 被阻止并提示无法连接对象存储。  
**原因：** `http://localhost:3000` 与 `http://127.0.0.1:3000` 是不同来源。  
**处理：** 为当前精确来源配置允许 `HEAD, GET, PUT` 的规则；临时隧道结束后移除其来源。  
**复测：** Presign、PUT 200、后端 HEAD `uploaded`、下载签名和临时对象清理均通过。

### 6.3 上传后页面刷新或状态丢失

**现象：** 视频上传完成后页面回到初始状态。  
**处理：** 使用后端真实 task UUID 恢复任务，刷新后继续轮询，不要求重复上传。  
**复测：** 刷新和重新打开同一地址均恢复任务阶段。

### 6.4 双语证据不足

**现象：** 任务在分析阶段失败，错误为 `BILINGUAL_EVIDENCE_INCOMPLETE`。  
**原因：** 契约要求双语，但 ASR 逐字稿没有完整中文译文。  
**恢复：** 纯中文课堂关闭双语并重试；英文/混合课堂上传带时间轴 SRT/VTT，重新从视频生成
ASR 并对齐译文。系统不静默翻译或忽略契约。  
**复测：** 浏览器同时上传 MP4 与 VTT 后，4/4 片段具有译文并完成 Agent 分析。

### 6.5 报告为空或无法载入

**现象：** 报告深链接无法加载，或尚无可纳入结论。  
**处理：** 恢复会话；检查所有结论是否已复核；服务端按接受/修改状态创建或读取报告。  
**复测：** 空报告可持久化，完成复核后可预览并导出；驳回项不进入报告。

### 6.6 旧进程消费新任务

**现象：** 当前代码与运行行为不一致，或任务使用旧契约失败。  
**处理：** 启动脚本通过锁和实例检查阻止重复 Worker/Agent；更新代码后停止旧进程再启动。  
**复测：** 同一服务不会被重复启动，日志可用 `trace_id` 对应当前实例。

## 7. 教师人工试用脚本

### 7.1 试用者与资料

试用者应为未参与相关功能开发的成员或目标教师。使用一份新的、有权处理且未写死结果的课堂
视频，可附课件或双语材料。开发者只观察，不代替点击或解释按钮位置。

### 7.2 核心任务

1. 打开网页并创建课程与课堂；
2. 用自然语言说明复盘目标并确认契约；
3. 选择正确资料类型，完成上传并理解格式、大小和失败提示；
4. 观察处理状态并在失败时决定如何恢复；
5. 校订逐字稿、说话人或译文；
6. 从结论跳到视频时间、原文或课件证据；
7. 逐条接受、修改或驳回，确认保存后自动进入下一条；
8. 在全部复核后编辑、预览并导出报告。

### 7.3 观察点

- 是否无需讲解就找到下一步；
- 是否能分辨事实、判断和建议；
- 是否理解 AI 结果需要人工确认；
- 是否能定位证据和识别失败原因；
- 是否误以为进度、译文或报告是系统伪造；
- 电脑与手机是否存在遮挡、字体过小或键盘不可达。

### 7.4 当前结论

该正式试用尚未完成。开发者已完成多轮浏览器操作与 UI 调整，但不能代替非开发教师验收。
试用后必须记录原问题、修改、同场景复测和仍未解决的限制。
