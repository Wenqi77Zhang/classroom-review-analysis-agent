# 课堂复盘与教学分析 Agent：测试与验收记录

> 本文统一记录测试方法、样例许可、阶段验收、失败恢复、真实 E2E 和剩余门禁。  
> 产品范围与完成度见 [`../docs/product-and-technology-handbook.md`](../docs/product-and-technology-handbook.md)。

## 1. 验证口径

### 1.1 状态定义

| 状态 | 判定方式 |
|---|---|
| 自动化通过 | 指定命令在记录基线执行成功 |
| 技术链路通过 | 真实数据经过代码、数据库、模型或工具并得到可核查结果 |
| 人工通过 | 按步骤实际操作并保存现象、追踪号或输出摘要 |
| 局部通过 | 部分阶段真实通过，但仍有明确缺口 |
| 未完成 | 没有实现，或没有足够证据证明可用 |

Mock、静态页面、固定录像和 TODO 不能证明真实链路。条件跳过的测试必须说明缺少何种外部服务，
不能并入通过数量。开发者操作不等于非开发教师用户验收。

### 1.2 证据最小集

每次关键验收至少记录：

- 日期、分支或提交；
- 输入类型、来源/许可和脱敏状态；
- 执行命令或浏览器步骤；
- 结果、失败阶段和安全追踪号；
- 问题、修改和复测结论；
- 未覆盖范围。

不得记录视频内容、学生身份、Cookie、Authorization、服务令牌、数据库密码、对象存储密钥、
完整预签名 URL 或模型隐藏推理。

## 2. 自动化与发布命令

### 2.1 一键验证

Windows：

```powershell

```

macOS/Linux：

```bash

```

扫描。任何一步失败都应返回非零退出码；真实浏览器执行仍须连接已经启动的完整系统。

Python：



## 3. 测试数据与隐私

### 3.1 数据分层

| 层级 | 用途 | 仓库策略 |
|---|---|---|
| 合成小样例 | 单元测试、边界与错误码 | 可提交，无真实身份信息 |
| 来源已核实但未获复用授权的公开课 | 仅限本地私有技术验收 | 只记录官方来源、哈希和权利边界，不提交或公开分发媒体；发布前必须替换或补授权 |
| 私密课堂 | 未来隐私场景 | 默认本地处理，须单独授权与影响评估 |

真实样例至少包含一门计算机或人工智能课和一门人文社科课；优先中英混合以展示双语能力，
但不要求必须有答疑环节。若只完成其中一个样例，不得声称覆盖两类课程。

### 3.2 输入身份

每个真实输入使用内部 `case_id`，记录来源 URL、许可、下载日期、文件哈希、时长、语言和是否
脱敏。公开仓库只保留这些元数据的安全摘要。第二输入必须与第一输入内容不同，不能只是重命名。

### 3.3 双语材料

教师补充译文只接受 UTF-8 SRT/VTT，并检查时间范围、顺序、重叠、空片段和中文覆盖。
补充译文用于对齐，不替代视频、FFmpeg 或 ASR 原文。纯中文课堂可以关闭双语契约；英文或中英
混合课堂若要求双语而译文不完整，系统必须失败关闭。

## 5. 真实双输入技术 E2E

### 5.1 前置条件

- 使用两段内容不同的真实课程视频，不提交到仓库；官方来源页已核实，书面复用授权仍须在公开演示前补齐，或替换为单独许可的媒体；
- PostgreSQL、私有 B2、FastAPI、Worker、Ollama Agent 和前端均使用当前代码；
- Worker/Agent 服务令牌不同；
- 浏览器来源与 B2 CORS 精确匹配；
- 日志和截图已脱敏。

### 5.2 已验证链路

1. 两门课程分别建立演示会话、课程、课堂和已确认分析契约。
2. 后端分别签发限时 PUT，将真实 MP4 上传到私有 B2，并由 HEAD 核对对象、大小和类型。
3. Worker 从受限下载 URL 获取对象，完成 FFmpeg、Whisper 和时间戳逐字稿写回。
4. Agent 读取契约与证据，调用 Ollama `qwen3.5:4b`；动态 Grammar 只允许计划内 Skill、结论类型
   和本任务证据 UUID，并对契约错误或缺失分析层执行有界修复。
5. AI 课任务 `c341139b-be92-42e8-aeca-197719025bdd` 成功：182 段逐字稿，事实/判断/建议各一条；
   分别接受、修改、驳回后，报告只纳入前两条。
6. 人文课任务 `e86e462c-3ec2-4862-8625-1e12268c9211` 成功：113 段逐字稿，5 条事实、1 条判断、
   1 条建议；分别覆盖接受、修改和驳回，报告纳入 6 条、排除 1 条。
7. 两门课程均实际生成并解析 Markdown、HTML、PDF；PDF 各 1 页且可提取非空文本。
8. 两份当前 ASR 与配套原始 ASR 的规范化文本序列相似度均为 1.0。配套 ASR 未经人工校订，
   该数值只能证明文本一致，不能写成识别准确率或地面真值。

本地脱敏摘要位于被 Git 忽略的
`data/local-inputs/validation-runs/20260820T202103Z/summary.local.json`。摘要不含令牌或预签名 URL；
公开视频、逐字稿和导出报告均不提交仓库。

### 5.3 真实失败与修复

- AI 课首次暴露本地模型输出计划外 Skill；修复后 grammar 只允许本轮计划 Skill，后端白名单仍
  作为第二道门禁。
- 小模型只输出事实层时，系统不把不完整结果写回，而是分别请求缺失的判断/建议并再次校验。
- 人文课曾因模型虚构证据 UUID 以 `SCHEMA_INVALID` 失败；将真实证据 UUID 收紧进 grammar 后，
  原任务重试成功。Trace 只保存错误位置和类型，不保存无效模型原文。
- 人文课末尾约 25 秒没有语句。测试发现 API 原先用最后一句结束时间代替完整音频时长；现已把
  FFmpeg 抽取音频时长独立持久化，并通过 PostgreSQL 集成测试验证 2000 ms 媒体、1900 ms
  最后语句仍返回 2000 ms。旧任务无该字段时才兼容回退。
- 真实英文课堂首次在“双语对齐”阶段以 `TRANSLATION_SCHEMA_INVALID` 失败。脱敏诊断确认最后一条
  ASR 片段在约 7.8 秒内出现 437 字符不间断重复串，属于静音尾部幻觉；同时本地小模型在末批
  6 条输入中只返回 4 条。修复采用两道失败关闭门禁：ASR 只剔除“极端字符速率 + 超长不间断词元
  + 低字符多样性 + 高重复三元组”同时成立的异常片段；翻译 Schema 失败时执行有界拆批、单条重试
  和长句拆分，但网络/服务错误不重试为成功，也不接受缺行、错序或空译文。
- 原失败任务 `29242b4d-804a-4149-8d1c-d19e8cf4b0d5` 在同一真实输入上重试 1 次后成功，Trace
  `88705d22fcab4470a261e4461dbbb218`。46 条原始 ASR 中质量门禁剔除 1 条异常片段，45/45 有效片段
  均有非空中文译文，`has_translation=true`，并生成 3 条可复核结论。验证过程没有输出课堂原文、
  译文、令牌或模型隐藏推理。

### 5.4 结论边界

该验收证明两条不同真实数据技术链路、一条真实英文课堂自动翻译链路和一条重建课件证据技术链路，
不证明媒体复用授权、获授权原始课件的浏览器人工操作或非开发教师独立操作。正式部署由 8.8 的
独立生产证据支持；只有真实用户与材料权利等剩余门禁通过后，才能声明全部 M1 验收完成。

## 6. 失败与恢复

### 6.1 浏览器会话失效

**现象：** 深链接报告或任务返回 401，页面提示建立安全演示会话。  
**处理：** 通过服务端 `/api/session/demo` 设置短期 HttpOnly Cookie，再重试原请求。  
**边界：** 不把 JWT 写入 `localStorage`，不在错误信息中输出令牌。

### 6.2 B2 CORS 来源不一致

**现象：** 预签名成功，但浏览器 PUT 被阻止并提示无法连接对象存储。  
**原因：** `http://localhost:3000` 与 `http://127.0.0.1:3000` 是不同来源。  
**处理：** 为当前精确来源配置允许 `HEAD, GET, PUT` 的规则；临时隧道结束后移除其来源。  
**复测：** Presign、PUT 200、后端 HEAD `uploaded`、下载签名和临时对象清理均通过。

### 6.3 上传后页面刷新或状态丢失

**现象：** 视频上传完成后页面回到初始状态。  
**处理：** 使用后端真实 task UUID 恢复任务，刷新后继续轮询，不要求重复上传。  
**复测：** 刷新和重新打开同一地址均恢复任务阶段。

### 6.4 双语证据不足

**现象：** 任务在分析阶段失败，错误为 `BILINGUAL_EVIDENCE_INCOMPLETE`。  
**原因：** 契约要求双语，但 ASR 逐字稿没有完整中文译文。  
**恢复：** 纯中文课堂关闭双语并重试；英文/混合课堂可使用本地自动翻译，也可上传带时间轴
SRT/VTT 作为教师优先译文。系统不静默忽略契约，不接受缺行或空译文。
**复测：** 浏览器同时上传 MP4 与 VTT 后，4/4 片段具有译文并完成 Agent 分析；真实英文课堂
自动路径在一次失败恢复后得到 45/45 有效译文和 3 条结论。

### 6.5 报告为空或无法载入

**现象：** 报告深链接无法加载，或尚无可纳入结论。  
**处理：** 恢复会话；检查所有结论是否已复核；服务端按接受/修改状态创建或读取报告。  
**复测：** 空报告可持久化，完成复核后可预览并导出；驳回项不进入报告。

### 6.6 旧进程消费新任务

**现象：** 当前代码与运行行为不一致，或任务使用旧契约失败。  
**处理：** 启动脚本通过锁和实例检查阻止重复 Worker/Agent；更新代码后停止旧进程再启动。  
**复测：** 同一服务不会被重复启动，日志可用 `trace_id` 对应当前实例。

### 6.7 前端误连另一个本地项目

**现象：** 页面可以打开，但保存复盘目标提示请求失败；`/api/session/demo` 返回 404，而启动脚本仍称
服务已启动。

**原因：** 8000 端口属于另一个 Codex 项目，课堂后端绑定失败；旧启动器未等待真实健康状态便继续
启动前端、Worker 和 Agent。

**处理：** 课堂后端默认迁移到 8100；统一启动器先检查 3000/8100，再验证课堂后端专属健康响应与
前端代理，最后才启动 Worker/Agent。

**复测：** `http://127.0.0.1:8100/health` 返回 `status=ok` 和 `app_env=development`，
`http://127.0.0.1:3000/api/backend-health` 返回 `reachable=true`，经前端创建演示会话返回 HTTP 200。

### 6.8 开发环境 CSP 阻断 React 调试工具

**现象：** 本地开发页面出现 `eval() is not supported in this environment`，React/Next 调试界面
持续报错；生产构建不受影响。

**原因：** 生产级 `script-src` 被原样用于开发服务器，而 React 开发调试功能需要 `eval()` 重建调用栈。

**处理与复测：** 仅当 `NODE_ENV=development` 时加入 `unsafe-eval`，生产模式仍不允许该能力；
契约测试同时锁定两条分支，避免为了方便调试而永久降低线上 CSP。

## 7. 教师人工试用脚本

### 7.1 试用者与资料

试用者应为未参与相关功能开发的成员或目标教师。使用一份新的、有权处理且未写死结果的课堂
视频，可附课件或双语材料。开发者只观察，不代替点击或解释按钮位置。

### 7.2 核心任务

1. 打开网页并创建课程与课堂；
2. 用自然语言说明复盘目标并确认契约；
3. 选择正确资料类型，完成上传并理解格式、大小和失败提示；
4. 观察处理状态并在失败时决定如何恢复；
5. 校订逐字稿、说话人或译文；
6. 从结论跳到视频时间、原文或课件证据；
7. 逐条接受、修改或驳回，确认保存后自动进入下一条；
8. 在全部复核后编辑、预览并导出报告。

### 7.3 观察点

- 是否无需讲解就找到下一步；
- 是否能分辨事实、判断和建议；
- 是否理解 AI 结果需要人工确认；
- 是否能定位证据和识别失败原因；
- 是否误以为进度、译文或报告是系统伪造；
- 电脑与手机是否存在遮挡、字体过小或键盘不可达。

### 7.4 当前结论

该正式试用尚未完成。开发者已完成多轮浏览器操作与 UI 调整，但不能代替非开发教师验收。
试用后必须记录原问题、修改、同场景复测和仍未解决的限制。
