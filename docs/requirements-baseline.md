# 需求基线

## 必须实现

1. 对话发起复盘任务，Agent 追问分析范围、重点和判断条件，教师确认后处理。
2. 上传真实课堂视频、课件或逐字稿；真实视频链路不可由现成逐字稿替代。
3. 视频持久保存到对象存储；数据库只保存对象地址、归属、状态和业务数据。
4. 显示上传、音频抽取、分段、识别、翻译和分析的真实状态；失败可重试。
5. 从视频生成带时间点逐字稿；英文或中英混合课堂保留英文原文和逐句中文译文。
6. 教师可修改逐字稿、说话人和译文。
7. 分析区分事实、判断和建议，每条结论连接视频、原文、课件页或画面证据。
8. 教师可接受、修改或驳回结论，并保留内容版本和确认状态。
9. 报告只组合已接受或已修改确认的内容，支持编辑、预览和导出。
10. 更换视频后重新处理并产生与新输入对应的新结果。
11. 至少验证一个完整成功流程、一个常见失败场景、两个账号隔离和一次真实试用迭代。
12. 提供可访问网页、完整源码、配置与部署说明和共同小组报告。

## 使用边界

- 系统辅助教师复盘，不自动替学校给教师打分。
- 无证据判断不得进入最终报告。
- 模拟、部分实现和未实现必须如实标注。
- 里程碑 M2、M3 不得挤占里程碑 M1。
