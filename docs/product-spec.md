# 产品方案

## 核心流程

1. 创建课程与课堂。
2. 通过对话说明复盘目标。
3. Agent 追问并形成分析契约。
4. 上传视频、课件或逐字稿。
5. 查看真实处理状态。
6. 在证据工作台核对逐字稿、视频、课件和分析。
7. 接受、修改或驳回结论。
8. 编辑、预览和导出仅包含已复核内容的报告。

## 高价值交互

- 分析契约：处理前确认分析范围、指标、证据条件和隐私模式。
- 证据工作台：播放器、逐字稿、课件与分析卡片联动。
- 证据账本：记录模型、Prompt、Skill、证据和教师修改版本。

## 页面责任

- 成员 1：首页、登录、课堂创建、对话、上传入口、任务看板和报告页。
- 成员 2：任务详情中的播放器、时间轴、双语逐字稿、证据卡片和复核控件。
