## 样例

- 一段计算机或人工智能公开课。
- 一段人文社科公开课。
- 每段记录来源、许可、版本、语言和使用目的；视频不提交到公开仓库。

## 必测流程

1. 使用非预置输入完成核心全链路。
2. 更换视频后产生不同逐字稿和分析。
3. 制造一个识别或外部服务失败，页面提示且可重试。
4. 两个账号验证数据隔离。
5. 非开发同学独立操作并记录问题。
6. 修改后使用同一任务复测，保存前后结果。
