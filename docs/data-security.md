# 数据、隐私与安全

- 公开课可使用已记录来源与许可的云服务；私有课堂默认本地处理。
- M1 的公开课演示视频进入 Backblaze B2 私有 Bucket；数据库不保存视频二进制。
- 所有资源按用户、课程、课堂和任务记录归属。
- 两账号必须通过后端权限验证实现隔离。
- 预签名 URL 必须限时、限对象、限操作。
- B2 仅使用限制到指定 Bucket 的应用密钥，不使用主密钥；长期密钥只放在后端/Worker 环境变量中，不进入前端、日志、报告或 Git。
- 对象键不得包含教师姓名、邮箱等直接身份信息；使用系统生成的不可猜测 ID。
- 默认 7 天保留期，到期或用户删除课堂时清理原始与派生对象，并记录不含签名 URL 和密钥的删除审计事件。
- M1 不向云端上传真实私密课堂资料；未来如处理私有课堂，必须先取得授权并重新完成隐私影响评估。
- API Key、Cookie、令牌和密码不得进入前端、仓库或日志。
- 临时音视频在处理结束或失败清理后删除。
- 删除流程必须同时处理业务记录、对象和审计状态。
- 公开仓库不得包含真实课堂视频或个人信息。
