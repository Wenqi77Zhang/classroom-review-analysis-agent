# M2 同课程第二轮真实课堂验收包

> 用途：指导教师用两次彼此独立、但属于同一课程的真实授课完成 M2 教学改进验收。该文档是执行清单，
> 不是已经发生教学改善的证明。未实际授课、未执行行动或没有可定位证据时，必须记录为证据不足。

## 1. 使用边界与隐私

两次课堂应由有权处理相关教学资料的教师组织。录制前应依据所在学校规则取得必要授权，并向参与者
说明用途、访问范围、保留期限和删除方式。优先采用不拍摄学生正脸的机位；不要在课程名、课堂名、
改进说明或报告中填写学生姓名、学号、联系方式、健康信息或其他个人身份信息。

若任何参与者不同意、授权范围不清楚，或材料包含不应上传的个人信息，应停止上传并先完成脱敏。
用于公开展示时，应改用仓库 `examples/public-demo/` 中的合成材料。

## 2. 开课前冻结验收口径

在第一次课堂复盘完成后，从教师已经“接受”或“修改确认”的一条建议建立改进循环。只选择一到三项
能够在第二次授课中真实执行、并能从视频、逐字稿或课件中观察到的行动。每项行动必须同时写明：

- 具体做法，例如“提出关键问题后静默等待至少 5 秒”；
- 成功标准，例如“逐字稿中能定位到等待后的学生解释，并且解释包含理由”；
- 证据位置，例如视频时间、逐字稿片段或课件页；
- 不满足标准时如何记录，例如“保持证据不足，不把课堂流畅度主观感受写成改善”。

在第二次授课开始前保存行动和成功标准，之后不要为了配合结果倒改标准。

## 3. 两轮课堂最低材料

第一轮和第二轮必须属于同一门课程，但第二轮必须是独立发生的再次授课，不能把同一录像切成两段。
每轮至少准备：

1. 一段能覆盖目标教学环节的课堂视频；
2. 实际使用的课件，若该环节没有课件则在课堂说明中写明；
3. 不含个人身份信息的课堂标题和日期；
4. 第二轮实际执行了哪些改进行动的简要记录。

建议使用相近的教学主题、难度、课堂时长和学习者阶段，降低不可比因素。若两轮差异过大，应在教师
复核中选择“证据不足”，而不是强行判断改善或退步。

## 4. 系统内执行顺序

1. 在“课程与课堂”中创建第一轮课堂，上传视频和可选课件，等待处理成功。
2. 逐条核对证据，接受、修改确认或驳回结论；只让确认后的内容进入报告。
3. 在“改进循环”中用第一轮课堂建立真实轮次，并把确认建议转为行动和成功标准。
4. 完成第二次独立授课后，在同一课程下创建第二轮课堂并上传实际资料。
5. 完成第二轮 M1 处理和教师复核，再回到改进循环关联第二轮课堂。
6. 生成证据对比。逐条打开第一轮和第二轮证据，确认定位、语义和行动目标确实对应。
7. 对每条候选选择接受、修改确认或驳回。没有足够第二轮证据时保留“证据不足”。
8. 只有行动确实执行后，才把行动进度改成“已执行”。
9. 在“教学效果门禁”中确认独立第二次授课和行动执行，并填写日期、非识别性对象描述、实际行动和
   可核查材料。声明本身不等于效果证明。
10. 到“课程总览”检查该循环是否被计入效果证据；下载报告并保存验收记录。

## 6. 通过条件与停止条件

单个 M2 循环只有同时满足以下条件，才能记为具备教学效果证据：第二轮是独立授课；登记行动已实际
执行并标为完成；系统生成的“有改善”候选保留当前来源；教师已接受或修改确认该候选；两轮证据可
定位且与同一成功标准对应；教师说明中记录了可核查材料。

出现以下任一情况应停止效果声明：复用同一录像片段；行动未执行；第二轮处理失败；证据定位失效；
两轮主题或学习者条件无法合理比较；候选依据个人身份信息；教师无法从原始材料确认系统判断。

M3 教学效果门禁要求至少两门不同课程分别存在一个通过上述条件的真实循环。单门课程或合成资料不能
补足该门禁。
