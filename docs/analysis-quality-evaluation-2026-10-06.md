## 改动范围

`analysis-v3` 先在当前账号、任务和教师确认的范围内，按目标与重点进行词项检索，再保留相邻逐字稿语境；最多提供 12 条证据，原文和译文合计最多 6000 字符，单条最多 800 字符。长文本只取连续片段，不改写原文。该检索方法不保证找全相关证据，中文目标与英文原文的关联仍依赖译文或共同词项。

模型给出每个证据 ID 对应的原文摘录，服务端核对数量、重复 ID、连续原文匹配以及账号、任务、范围和本次可见性。摘录不能来自另一条证据、未提供的长文本部分或仅存在于译文中。写入报告引用的是核验后的摘录。结构或摘录错误只允许一次重生；第二次失败则停止保存。反馈和 Trace 不记录无效模型原文。

候选数量为 0–3 条，不再强制补齐事实、判断、建议；没有可靠结论时任务给出补充材料或缩小目标的提示。三种类型的含义和后端报告契约保持不变，待复核或已驳回内容仍不能进入报告。原文字面匹配只证明引用来源，不能证明主张的语义正确，教师仍须逐条复核。

## 本机实测及限制

原 0.8B 模型在旧流程下两份样本均失败；新流程下仍有跨条拼接摘录，已被新门禁拒绝，没有因为编号存在而保存。不能宣称仅修改提示词就足以修复小模型质量。

同为上述本机 4B 权重时，旧流程的两份样本均生成 5 条候选，各调用 3 次模型。所谓“判断”和“建议”主要是内容摘要，并非依据标准作出的判断或可执行建议；微观经济学中还出现引用未包含的数学方法、人物以及边际效用解释。AI 初次请求约 20440 字符，微观经济学约 19541 字符。

新流程两份输入的初次请求约为 4750/4950 字符，缩短约 76%。AI 样本曾出现把两条原文拼接到一个 ID 的错误，初次核验拦截后，经一次有定位信息的修复生成 3 条候选；微观经济学直接生成 3 条事实。它们没有强行生成建议。AI 的两个事实及微观经济学的三个事实有相应原文支持；AI 的一条判断仍把局部材料推成“未直接建立对应关系”，应驳回或收窄。个别中文术语仍需润色。这是开发者代理复核的样本观察，不是统计准确率或教师认可。
