由成员 1 与 Codex 在合并提交中协作修复。

最终整合版保留成员 2 的四个组件及播放器—时间轴联动设计，并补充：

- 毫秒级时间契约和键盘可操作的逐字稿定位；
- 无真实授权地址时的播放器安全降级；
- 事实、判断、建议和证据定位的明确分层；
- 受控的教师复核状态及“尚未写入后端”边界；

合并审核后的自动化核验：`npm test` 四组测试通过、`npm run typecheck` 通过、
`npm run build` 生产构建通过。该结果证明当前前端契约与构建门禁通过，不等于真实媒体处理、
真实逐字稿或后端复核持久化已经实现。
