# 课堂复盘与教学分析系统：小组报告

> 当前为 2026-08-20 过程稿，事实基线为当前 `main`、真实纵向验收及待合并交互修复。本文不代表
> 里程碑 M1 已完成；各成员仍需补充本人实现说明和脱敏证据。

## 1. 问题、背景与用户

系统面向需要复盘单节公开课的高校教师，目标是把课堂视频转化为可定位、可复核的
教学分析，而不是自动给教师打分。每条判断必须关联时间戳逐字稿、视频、课件页或
画面证据；只有教师接受或修改确认的内容才允许进入报告。

## 2. 产品定位、流程与交互

成员 1 冻结了从“说明复盘目标—确认分析契约—上传资料—查看处理状态—核验证据—
人工复核—编辑和导出报告”的 M1 流程与 UI Baseline v1。当前真实课程/课堂、
B2 上传、任务、证据工作台与教师复核已经接入；报告分支已接入服务端持久化和
Markdown、HTML、PDF 导出，`/reports/demo` 仍保留独立演示边界。

## 3. 前端架构与证据工作台

Next.js 前端通过同源 BFF 调用后端，短期 JWT 保存在 HttpOnly Cookie，浏览器不接触
服务令牌或 B2 长期密钥。成员 2 的播放器、时间轴、双语逐字稿和证据卡组件已经合并，
并已通过真实逐字稿、结论、复核历史的 API 接线；浏览器同时上传视频与教师定时译文的
恢复路径已通过，真实课件画面与自动翻译 Provider 仍待接入。

## 4. 平台后端、数据与安全

FastAPI 与 PostgreSQL 已实现账号隔离、课程/课堂、S3 Provider、上传核验、任务租约、
逐字稿和结论的最小权限读写边界。真实 B2 上传由浏览器完成，数据库只保存对象元数据。
教师复核历史、报告持久化和三种服务端导出 API 已实现并有数据库测试；空报告的
会话恢复、标题持久化、预览与 PDF 下载已由成员 1 人工通过。2026-08-10 又以真实 Agent
结论验证 accepted/modified 纳入、原判断/rejected 排除，并完成 Markdown、HTML、PDF
真实对象存储下载。浏览器全程点击仍需复验。成员 3 仍需核对并补充本人实现说明。

## 5. 视频、逐字稿、翻译与专业规则

成员 4 已用两段不同真实视频验证 FFmpeg 音频抽取和本地 Whisper 时间戳逐字稿。
PR #20 由成员 1 协作补齐 `uploaded` 任务领取、B2 限时下载、大小/ETag 校验和
PostgreSQL 写回，并用一段获授权真实视频完成
`B2 → Worker → FFmpeg → Whisper → transcript` 验收。媒体流水线主责仍归成员 4；
浏览器上传的教师 UTF-8 VTT 已由 Worker 独立下载，并与重新生成的 ASR 按时间覆盖对齐；
该实测 4/4 片段具有译文并成功交接 Agent。它不是自动翻译能力。课件纵向证据、生产级
进程托管、自动翻译 Provider 及第二段不同远程视频尚未完成。

Agent 已实现结构化事实/判断/建议、任务与账号证据范围校验、隐私路由、稳定 Trace
结构和只组合 `accepted/modified` 的确定性规则。成员 1 暂代成员 5 的跨模块集成，
协作补出并已合并 Worker→Agent 原子交接、Agent 领取与续租、编排、结论写回、
任务完成和安全失败处理。2026-08-10 本地 `qwen3.5:4b` 以真实 Worker 逐字稿写入事实、
判断、建议各 1 条，均绑定同一 Trace 和时间证据。Agent 主责仍属于成员 5；专业 Skill
