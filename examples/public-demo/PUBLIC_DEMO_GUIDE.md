# Public demo kit

This directory provides two small, privacy-safe classroom rounds for the deployed Classroom Review Agent. Register an
account at <https://15.134.73.60.sslip.io>, then use these pairs in order:

1. `round-1-classroom.mp4` with `round-1-courseware.pptx`
2. `round-2-classroom.mp4` with `round-2-courseware.pptx`

For each round, create a classroom, upload the MP4 as the required video and the PPTX as courseware, confirm a focused
analysis contract, and start the task. After both tasks succeed, create an improvement cycle that links round 1 to
round 2. The second round adds an explicit success check, learner thinking time, peer comparison, and an explanation
prompt so reviewers can exercise evidence comparison without claiming a real teaching effect.

The kit is synthetic and licensed under CC BY 4.0. See `LICENSE.md` for attribution and `manifest.json` for exact
hashes. It validates product mechanics only. It does not provide teacher-usability evidence, real classroom evidence,
or teaching-effect evidence.
