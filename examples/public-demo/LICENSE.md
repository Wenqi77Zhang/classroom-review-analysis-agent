# Public demo material license

The four generated media and courseware files in this directory are original synthetic materials created for the
Classroom Review Agent project. They contain no student data, teacher data, institutional recordings, third-party
images, logos, music, or course-platform content.

The abstract classification background was generated specifically for this project with OpenAI ImageGen and contains
no reference image. The lesson text, narration, layout, video assembly, and courseware source are included here.

text and generation process.
